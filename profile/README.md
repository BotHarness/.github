## 我们在做什么

BotHarness 围绕 **持久身份、可查看的记忆和多 Bot 协作**，构建开源 AI 产品与开发工具。

我们的第一个产品是 **[DeepSeekBot](https://github.com/BotHarness/DeepSeekBot)**：基于 [DeepSeek Harness（DSH）](https://github.com/deepseek-ai/deepseek-harness) 的个人 AI Bot 团队。你可以创建研究员、设计师、工程师等 **PersonaBot**，和它们私聊、拉群、分派任务；每个 Bot 都有自己的身份与 Git-backed Memory，跨越对话、Session 和 Workspace 延续下来。

我们关心的不是多开几个聊天窗口，而是让这些伙伴能持续参与真实工作：

- **各有身份**：每个 PersonaBot 都有自己的名字、角色和执行归属。
- **记忆可见**：用普通 Git 文件保存记忆，方便查看、纠正和迁移。
- **一起做事**：通过群聊与任务委派协作，把进展和结果带回来。
- **连接日常工具**：通过 IM 适配器与 DSH 插件扩展能力，保留明确的权限边界。

## 一起把它做得更好

不必先读完整个代码库，也不必只贡献代码。

- **试用并反馈**：安装 DeepSeekBot，完成一个真实的小任务，把遇到的阻碍和期待告诉我们。
- **报告问题**：到 [Issues](https://github.com/BotHarness/DeepSeekBot/issues) 提交复现步骤、预期与实际结果；附截图或日志前，请先移除密钥与私人信息。
- **讨论想法**：在 [Discussions](https://github.com/BotHarness/DeepSeekBot/discussions) 分享使用场景、产品建议和你想做的 Bot。
- **提交改进**：修复一个问题、补充一页文档、改善一次交互，或分享可复用的组件与插件。先阅读目标仓库的贡献指南与 `AGENTS.md`（如有），并在相关 Issue 中确认范围。

**第一次来？** 从 [贡献指南](https://github.com/BotHarness/DeepSeekBot/blob/main/CONTRIBUTING.md) 开始；不确定从哪里入手，就来 [Discord](https://discord.gg/aEB2Ayhu7B) 聊聊。中文交流也欢迎加入 **QQ 群：1125565676**。

## About BotHarness

BotHarness builds open-source AI products and developer tools around **persistent identity, inspectable memory, and collaboration**.

Our first product, **[DeepSeekBot](https://github.com/BotHarness/DeepSeekBot)**, runs on [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). Create PersonaBots for research, design, or engineering; talk to them directly, bring them into a group, and delegate work. Each PersonaBot keeps its identity and Git-backed memory across conversations, sessions, and workspaces.

Our ecosystem also includes [BotUI](https://github.com/BotHarness/BotUI) for agent-product UI, [BotPixel](https://github.com/BotHarness/BotPixel) for pixel avatars and animation, and [dsh-skill](https://github.com/BotHarness/dsh-skill) for plugin development.
